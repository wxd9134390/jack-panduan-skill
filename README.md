# 四海公考·判断推理体系 Skill

基于四海公考黄老师 / 花生十三 2026 系统班课程（判断推理 16 讲）蒸馏而成。帮助行测考生识别题型、套用解题模板、快速定位答案。

## 安装

```bash
# 通过 skill-creator 或 search_and_install_skills 安装
# 或手动克隆到 ~/.workbuddy/skills/
```

## 核心能力

- **题型分类框架**：论证类 / 推出类 / 分析类
- **归因论证框架**：对比实验归因、时间对比归因、质疑与支持的强弱判定
- **三圈质疑与四圈致词**：同因异果、异因同果、无因有果
- **直接根本原因**：原观点 vs 反对者的判定逻辑
- **一般质疑三段攻击**：攻击优先级——推理漏洞 > 结论无中生有 > 论据有误
- **定义题抓被定义词**：反对机械匹配，强调抽象迁移

## 使用

在 WorkBuddy 对话中直接讨论判断推理题目，系统会自动匹配此 skill。

或主动触发：
```
用四海判断推理体系来分析这道题
```
